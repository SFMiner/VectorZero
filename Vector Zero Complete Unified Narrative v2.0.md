# Vector Zero: Complete Unified Narrative

## Core Themes

- **Primary:** Connection creates capability; unity unlocks potential
- **Secondary:** Mathematical consciousness experiencing itself
- **Philosophical:** Identity through limitation and transcendence

## Death/Rebirth Mechanic

- **The Inversion:** Meeting one's inverse self returns the player to origin (0,0)
- **Knowledge Persistence:** All mathematical understanding and puzzle solutions remain known
- **Physical Loss:** Companions and abilities must be regathered
- **Optional Challenge:** Complete the game without ever "zeroing out"

## Other Disappearances (Not Death)

- **Cancellation:** Objects that sum to zero vanish together (+3 and -3 cancel)
- **Negative Realm Transport:** Objects falling into negative zones become their negative equivalents
- **Not destruction:** Mathematical transformations, not disappearance

### Stage 9: The Balance Puzzle (Equations & Solving)

**Mathematical Concepts:** Equations, solving for unknowns, constants vs. variables

**Narrative:** **Setup:**

- Balance scale blocks the path
- Must be balanced to proceed
- Left platform: Y (variable, can change)
- Right platform: X (variable, can change) + Z (unknown, fixed to platform)
- Scale inscription: **Y = X + Z**

**Problem:** Z is attached to the scale and won't reveal its value. Must solve for Z.

**Solution Process:**

```
Method 1: Simplification
- Set X = 0
- Adjust Y until balanced
- Y = 3 when balanced
- Therefore: 3 = 0 + Z
- Z = 3

Method 2: Any values
- Set Y = 10
- Adjust X until balanced (X = 7)
- From Y = X + Z: 10 = 7 + Z
- Z = 3
```

**Z's Revelation:**

```
[After solving, Z glows and speaks for first time]

Z: "I am 3. I have always been 3."
Vector Zero: "But you were labeled Z, like a variable..."
Z: "I wore the label of a variable, but I was never variable. 
    I was always constant. Always 3."
Axiom: "You were an unknown constant. We didn't know your value, 
       so you were written as Z. But you never changed."
Z: "Correct. X and Y are variables—they can be many values. 
    I am a constant—I can only ever be one value: 3."
```

**Key Distinction Established:**

- **Variables (X, Y):** Can change values—they vary
- **Unknown Constants (Z):** Fixed value but hidden, written as letters until solved
- **Known Constants (+3, ×2):** Fixed values, immediately visible

**Mechanics:**

- Balance scale puzzle requiring equation solving
- Manipulate variables to discover constant
- Introduction to equation balancing (what you do to one side, do to the other)

**Educational Concepts:**

- Equations as relationships
- Solving for unknowns
- Variables vs. constants (unknown and known)
- Balancing equations

**Emotional Arc:** Puzzle → Discovery → Distinction understood
